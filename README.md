# Teaching Device Monitoring System

Du an Python mo phong Delegate va Event cho he thong thiet bi giang day.

## Chay
Tu thu muc goc:
```bash
python -m src.main
python -m unittest discover -s tests -v
```

## Chuc nang
- Quan ly ProjectorRemote, AirConditionerRemote, WirelessMicrophone.
- Su kien StatusChanged va AlertRaised.
- Subscriber, callback filter, coordinator.
- Kiem tra du lieu pin/tin hieu trong [0, 100].
